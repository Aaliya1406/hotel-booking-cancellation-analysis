
# Hotel Booking Cancellation Analysis

## Project Overview
This project explores hotel booking data to understand reservation cancellation patterns and identify factors associated with cancellations.

## Objectives
- Analyse overall hotel booking cancellation rates.
- Compare cancellations between City Hotels and Resort Hotels.
- Study cancellation patterns by arrival month.
- Analyse the relationship between lead time and cancellations.
- Explore cancellation patterns by market segment, deposit type, and customer type.
- Identify useful business insights from the data.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The project uses the Hotel Booking Demand dataset.

The raw dataset is not included in this repository because it contains guest-identifying information. Download the dataset from its original Kaggle source and place it inside the `data` folder as `hotel_booking.csv`.

## Key Findings
- Total records analysed: 119,384
- Overall cancellation rate: 37.04%
- City Hotel cancellation rate: 41.72%
- Resort Hotel cancellation rate: 27.76%
- Median lead time for cancelled bookings: 113 days
- Median lead time for non-cancelled bookings: 45 days

## Project Structure
- `data/` – Dataset instructions
- `notebooks/` – Jupyter notebooks
- `images/` – Project image resources
- `requirements.txt` – Required Python libraries

## How to Run
1. Clone or download this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Download the dataset and place it in the `data` folder.
4. Open the notebook in Jupyter Notebook.
5. Run all cells.

## Conclusion
This exploratory data analysis identifies important patterns in hotel booking cancellations and provides insights that may help hotels better understand cancellation behaviour.
